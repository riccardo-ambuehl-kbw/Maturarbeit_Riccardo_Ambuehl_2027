# KI-Nutzung dokumentieren

Dieser Ordner dient dazu, die Nutzung von KI-Tools in der Maturarbeit transparent zu dokumentieren. Dadurch bleibt nachvollziehbar, welche Teile der Arbeit mit Unterstützung von Tools wie ChatGPT, Codex oder anderen Hilfsmitteln entstanden sind.

Die Dokumentation ersetzt keine fachliche Prüfung. Alle KI-generierten Inhalte müssen kritisch kontrolliert, angepasst und eigenständig verantwortet werden.

## Pro KI-Nutzung festhalten

Für jede relevante Nutzung sollten folgende Informationen dokumentiert werden:

- Datum
- Tool, zum Beispiel ChatGPT, Codex oder Zotero Helper
- Zweck der Nutzung
- Konkreter Prompt oder Zusammenfassung des Prompts
- Ergebnis oder Output
- Welche Teile übernommen wurden
- Welche Teile manuell geprüft oder angepasst wurden
- Bewertung der Zuverlässigkeit
- Reflexion: Was wurde selbst entschieden?
